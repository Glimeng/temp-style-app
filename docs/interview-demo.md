# 知温面试演示

## 演示前 2 分钟

在服务器终端执行以下操作，将共享演示账号恢复为标准状态。密钥保存在服务器的 `.env` 中，不要展示给面试官，也不要提交到 Git。

```bash
cd /opt/zhiwen-demo
set -a
source .env
set +a
curl -X POST \
  -H "X-Demo-Reset-Key: $ZHIWEN_DEMO_RESET_KEY" \
  http://127.0.0.1:8787/api/demo/reset
curl http://127.0.0.1:8787/api/health
```

预期先返回 `演示数据已恢复到标准状态`，再返回健康检查 JSON。随后在浏览器打开 `http://111.231.165.55` 并刷新一次页面。

## 三分钟讲解路径

### 0:00 - 0:25，场景与登录

打开首页，说明知温服务于早晚温差和空调环境下的日常通勤：它把天气、个人衣橱和体感反馈串成可解释的穿搭建议。点击右上角头像或页面中的“登录体验”，选择“微信授权登录”。

说明：当前线上使用隔离的演示账号，避免面试过程要求扫码或让多位访问者污染真实账号；后端已经验证登录态，并按用户 ID 隔离数据。

### 0:25 - 1:05，天气与推荐

回到首页，指出北京当天 `12 - 21` 度、早晚微凉。打开“轻暖通勤”卡片，展示三段式体感预测：早晨、办公室和晚间，并解释推荐的是可增减的叠穿结构，而非只给一件衣服。

### 1:05 - 1:45，衣橱与可解释性

在详情中点击“换一件”，展示同类别候选按匹配度排序。返回后进入“衣橱”，筛选“外套”或搜索“防风”，展示每件衣物的类别、颜色、标签、可穿状态。点击“墨绿防风夹克”的“可穿”状态一次，说明不可穿衣物会自动从推荐中排除；再点一次恢复，保持后续演示稳定。

### 1:45 - 2:25，闭环反馈

回到首页，点击“今天穿这套”，在详情页选择“刚好”。说明该操作会调用后端穿着记录和反馈接口，后续版本会根据持续反馈校准保暖层与推荐排序。

### 2:25 - 3:00，工程实现与部署

说明前端为 React，后端为 Node API，衣橱、搭配、穿着与反馈均有实际接口；使用 Docker Compose 部署，Nginx 统一提供公网 HTTP 入口，应用端口仅监听服务器本机。现场可打开 `/api/health` 证明服务健康。

## 演示边界

- 天气和衣物识别使用固定演示数据，避免第三方服务波动影响面试。
- 演示账号由所有访问者共享，因此每次正式演示前执行一次重置。
- 不要在公开网页放置重置按钮，也不要泄露 `ZHIWEN_DEMO_RESET_KEY`。
